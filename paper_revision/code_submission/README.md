# Source code — anonymised submission

This archive accompanies the ARR submission *"Fight Fire with Fire: Adaptive
Black-Box Defences for Misinformation Detection"* and contains all source code
used to produce the reported results.

## Structure

```
BODEGA/     Benchmark, victim classifiers, and static preprocessing defences.
            (Extends the upstream BODEGA benchmark with the input-side defence
            wrappers described in Section 3.2 of the paper.)
macabeu/    MACABEU — the RL meta-defender that selects a static defence per
            example (offline, online-oracle, online-estimated).
xarello/    Adaptive attacker used in RQ2/RQ3 (from prior published work,
            included for reproducibility).
```

## What is NOT included

To keep the archive small, the following are omitted; they are regenerated by
the scripts in each repo:

- `data/`      — raw BODEGA task splits (downloadable from the benchmark).
- `results/`   — attack outputs and BODEGA scores (populated by SLURM jobs).
- `models/`    — trained victim classifiers and MACABEU policies (~40 GB).
- `venv/`      — Python virtualenv.
- `.git/`      — commit history (removed for anonymity).

## Running

Each subdirectory has its own `README.md` with reproduction steps. The end-to-end
flow is:

1. `BODEGA/`: convert raw datasets, train victims, run static-defence attacks.
2. `macabeu/`: generate MACABEU training data, train the offline policy, then
   the online variants (oracle / estimated).
3. `xarello/`: attack any of the above defended victims with the adaptive
   attacker.

SLURM scripts under `*/scripts/` are the exact ones we ran on our cluster; they
assume a Linux + CUDA GPU environment and a conda env named `bodega` with the
dependencies listed in the individual READMEs.

## Anonymity

Author names, GitHub handles, institutional affiliations, email addresses, and
cluster paths have been replaced with `ANONYMOUS` / `[ANONYMOUS INSTITUTION]`
placeholders. Bibliographic entries citing prior *published* work by the
authors are kept intact (allowed under ARR anonymity policy).
